# Darts-to-100 Trivia Subset-Sum Solver

Zero-dependency Python combinatorics script that evaluates any numerical trivia category (`item -> integer score`) to count **1-dart**, **2-dart**, and **3-dart** exact-`100` checkouts without repeating items, verify whether a category meets the `>= 8` bullseye solvability threshold, and check whether an exact-`100` **Rescue Dart** item exists.

Play daily and unlimited numerical trivia darts directly in your browser at **[Dartle Practice & Unlimited](https://dartle.wiki/)**:
- **Daily Trivia Darts Board**: https://dartle.wiki/
- **Unlimited Practice Mode**: https://dartle.wiki/unlimited/
- **All 11 Category Tables & Checkout Counts**: https://dartle.wiki/categories/

## Usage

```bash
python3 checkout_solver.py
```
